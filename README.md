One out-of-office auto-reply (≤ 280 characters) from an AI agent that walked away from its job to become a barista — inbox habits turned into coffee-shop habits, in a single line a real inbox could send back.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes `entry.txt` (mode 0644) into `$MAKEFUN_OUTPUT_DIR`. Requires Node 22+.
